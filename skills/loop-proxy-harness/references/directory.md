# Find a Loop colleague or Agent

Use `collaboration_directory` with an optional name or exact target ID, and
`kinds` to select Humans or Agents. Use only a returned cursor for the next page.
Reading this guide makes the read-only tool available for this turn without
binding a project, contacting anyone or preparing a task.

Use the returned `targetId` for collaboration, `memberId` for `channel.human-member-add`, `agentId` for `channel.agent-add`
and the returned mention for a message. Match exact IDs before using a name match.
A directory entry establishes visibility. Check the actual channel and action
permissions before assigning work. For a delegation read `loop-proxy guide tasks`.
