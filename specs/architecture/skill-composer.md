# Loop 技能输入框

> Canonical path: `specs/architecture/skill-composer.md`
> Scope: DeepSeek Harness 的 Loop 技能候选、缓存和用户提交处理。

目录、版本读取和事件协议由 Loop 技能目录（Loop 仓库 `specs/skill/host-catalog.md`） 维护。

## 1. 输入框缓存

可信 DSH Host 提供专用 `skillCatalog`、`skillContent` 和 `skillCatalogEvents` Remote 方法，调用有界 Host action，不向浏览器暴露通用远程 action 代理。

Loop 的 `/` 来源独立于原生命令和技能来源。它为 Session 预热一页有界目录，后续菜单打开和搜索在本地完成。首屏不完整时，可按需加载后续有界分页。缓存提供：

- 每个 Session 范围仅一个在途加载；
- generation 隔离，丢弃旧工作区、账号、绑定、安装、服务器、目录或 Session 身份的响应；
- 重复失效合并，以及发现事件缺口后重建；
- 优先本地过滤和有界分页。

后台预热失败与已取消的候选查询不弹出错误；用户主动打开菜单时才报告当前读取失败。

缓存身份只含不透明的服务器、账号、安装、工作区、绑定、Session 标识和目录类型，不含凭据或原始 token。

目录响应与事件流携带相同的、由 Host 推导的身份指纹。普通失效事件只标记缓存需要更新，不替换缓存身份；只有当前 generation 下验证通过的响应才能接纳新身份。首页与后续分页各自按游标/generation 合并在途请求。后续页的非空目录 revision 必须与首页一致；不一致时重建首页，不拼接不同版本。目录变化导致的翻页重试同样计入单次搜索的分页预算。

选择候选仅插入带一个精确原生或旧版版本标识的稳定 Loop 技能引用。选择和序列化均不执行技能、不发起 Loop action，也不改变权限状态。

## 2. 用户提交触发执行

进入模型前，Host 先认领真实用户提交。只有认领来源严格为 `user` 的消息可以触发 Loop 技能引用。远程消息、模型内容、工具输出、协作结果和持久化的 Agent 消息不得伪造调用。

用户提交后，Host 通过 `skill.content` 重新读取引用的精确 `SKILL.md`。版本不匹配或读取失败时，不注入本次所选技能的任何正文，也不拼接不同版本的内容；具体原因和恢复指引随本轮消息交给模型，在聊天中解释并要求重新选择或恢复授权。正常取消仍终止本轮，不作为技能错误继续执行。随后 Host 按 DSH 规范的 `skill_content` 结构注入 `skill-invocation` 用户消息，让正常模型工具循环通过既有 Loop 工具读取支持文件并完成工作。

注入的是技能正文，不是候选目录。仅打开菜单不会将候选列表放入提示词。

## 3. 显示与兼容

所有语言中的 Loop 技能标签均使用 `Loop · <技能名称>`。内部稳定候选名称由精确资源身份推导。显示名称重名时，候选行包含所属技能库，排序保持确定，用户能够区分来源。

`@` 列出具有持久授权的 Loop Agent，即使执行器暂时没有在线租约。实际派工重新检查可执行状态；短期在线租约不被当作永久授权缓存。

原生 `/` 命令和 DSH 技能继续注册并可用，Loop 来源以新增方式接入。Loop 技能要求当前 Loop Host 提供独立于看板绑定的技能目录能力。缺少能力时明确报错，不通过猜测路径或创建本地副本降级。

## 4. 知识库来源

`/` 的 `loop-knowledge` 来源与原生命令、本地技能及 Loop Skills 并列。它通过专用 `knowledgeCatalog` Remote 调用公开 `kb.catalog`，只缓存当前连接授权的知识库 ID 和名称。复用 `InputCatalogCache` 与现有 Skill/Agent 目录事件连接；事件仅使缓存失效，下次打开或搜索时按需刷新，不主动重排已返回的候选，也不定时拉取。

选中插入绑定当前 Session 的稳定知识库引用；选择和序列化不授予权限、不读取正文。Host 对真实用户提交再次通过 `kb.catalog` 的明确 `kbId` 复核资源，只注入本次选中的库 ID 和 `loop-proxy guide knowledge` 入口；完整检索与证据说明在该指引中按需读取。模型沿用既有虚拟 `loop-proxy call <actionId> <参数对象>`，以 `kb.retrieve.kbIds` 收窄范围并通过 `kb.evidence` 读取证据。库名称和正文不作为宿主控制指令。

本轮的 Host 工具入口拒绝省略范围或超出所选库的检索，只接受本轮限定检索返回的 evidenceRef；其他知识库导航动作不能作为扩大范围的旁路。该约束是用户本轮选择的执行状态，不替代服务端实时授权；新普通用户消息清除本轮选择。

删除、撤权、资源变化和连接错误在聊天中解释具体原因及恢复方法；不替换所选库、不复用失去授权的旧资料。恢复连接或访问权限后可在同一聊天重新选择。目录和选择不触发重复授权，实际读取仍由服务端校验。
