# 宿主同步与模型运行

> Canonical path: `specs/architecture/host-runtime.md`
> Scope: Loop-DSH 的本机同步、凭据访问与模型适配。

服务端协议以 Loop Host Sync（Loop 仓库 `specs/api/external-host-sync.md`） 与 模型访问（Loop 仓库 `specs/api/external-host-model-access.md`） 为准。

## 同步运行

会话捕获模块复用 DSH 官方 Session telemetry 和只读 observation，`loopNativeSyncWriterFactory` 提供原生持久队列。没有外部同步进程或 helper 回退。捕获与上传由同一 Host 生命周期管理，前台事件只调度后台工作，不等待网络。

默认只捕获登录期间观察到的新事件；显式开启历史上传后，后台分批读取可访问的历史。只有当前 Session 已授权且具有精确工作区映射时才持久入队。队列保留原 profile、账号与事件 ID，上传失败有界重试，服务端以事件 ID 去重。隐藏推理、原始工具参数、附件内容和凭据不随对话上传。

连接切换、撤权或会话失效时，迟到的授权检查和冷读取不能发布到新连接。会话失效先取消上传并等待在途捕获结束，再清理对应状态。停用插件不等于退出账号；重启只恢复已有明确准入的队列，不自动补传未授权历史。

上传状态使用原子本地回执，区分排队、上传、成功与失败。成功重试清除临时失败缓存；账号退出只清理其精确队列，不接管其他账号或未知状态。凭据和内核锁边界见[本机安全](local-host-security.md)。

## Host 责任

原生后端通过 DSH provider 保存模型 OAuth，将短会话 token 保存在内存，仅向模型 adapter 提供随机本地 key 和 loopback bridge。bridge 只监听 `127.0.0.1`。OAuth、refresh 和 Loop 会话 token 不进入模型上下文、项目文件、工具参数或子进程环境。

Host 复用 PiAiAdapter 处理支持的协议，注册稳定的 provider 路由，内部身份区分模型、供应商和协议。目录缺少容量元数据时，Harness 采用 131,072 token 上下文预算和 8,192 token 输出预算，以支持会话压缩与切换；该预算容纳 Harness 默认 65,536 token 压缩预留；它是客户端配置预算，不代表供应商真实上限。已有目录容量优先于该默认值。切换只影响下一次请求；在途调用保留原身份。标题和压缩调用必须关联原 Harness 会话及授权主体。

托管模型遵循网关发布的协议能力，不直接继承同名供应商模型的专用请求字段。DeepSeek 托管工具调用历史的 assistant `content` 使用字符串；空内容规范化为空字符串，实际 `reasoning_content` 和工具结果保持原样；上游未返回推理内容时使用协议要求的空字符串，不注入虚构推理或额外 assistant 轮次。

DSH 模型和同步使用同一 `loop.host` grant 的受保护凭据引用，分别受实时 `models.use` 与 `sync.upload` 权限控制。撤销该 grant 使本安装各用途失效；其他安装与独立连接保持自己的生命周期。账号状态只读取主 OAuth 和本机凭据完整性，不等待目录或同步任务。

普通业务动作使用当前连接的动作白名单和服务端资源授权，不依赖会话上传或本地频道绑定；
已有绑定仍须与当前连接一致。协作派工继续验证精确频道、实际用户消息和分享范围。
同步的 401 表示需要恢复授权；403 保留服务端权限拒绝原因，不自动发起登录。
设备与安装接口的字符串错误正文同样保留，不能因缺少结构化错误码而丢失原因。

模型插件复用 原生后端 的已有授权目录刷新接口，每次刷新结束后间隔 15 秒再次读取；不创建额外授权，也不另存模型目录。个人模型与当前工作区可执行的组织模型统一投影到 DSH 原生选择器，包括登录时目录为空而后来新增模型的情况。实际目录变化时通过公开 adapter 注册接口通知宿主；未变化不发布更新，当前默认和会话选择保持不变。刷新请求合并，退出插件取消在途读取；刷新完成后重读 原生后端 当前身份的目录，不采用旧刷新响应中的身份快照。

服务地址、工作区、账号或连接发生变化时，对应目录和会话状态必须更新，旧请求不能静默转用新身份。断开和注销撤销连接、停止新会话、取消关联本地请求并清理状态。服务端不把本地 bridge key 或安装元数据当作 OAuth 证明。
