# 将 DeepSeek Harness 连接到 Loop

先从 [DeepSeek Harness 官网](https://deepseek.com/harness/)下载安装 DSH 桌面端，再[下载 Loop 插件包](https://github.com/flowbehappy/loop-dsh/releases/latest/download/loop-dsh.tgz)。按[安装和登录步骤](../../../../README.md#安装和登录)将插件装入 DSH 并连接工作区。

## 登录与权限

在 DSH 左下角“更多 → 登录”确认 Loop 服务地址，在外部浏览器完成授权。Host 保存当前安装的一对凭据；Agent 动作、模型和会话上传使用统一连接，并分别接受服务端用途与资源检查。不同安装可单独撤销。页面登录和 Worksite 有各自的授权边界。

在 Loop 账号设置的“个人助手”中管理操作和资源权限。默认读取、写入、模型与上传开启，删除和管理关闭。直接描述要办的事即可。助手先使用自己的权限，缺少权限时会在原聊天中请求你授权可代办的操作。助手准备具体范围，点击“前往 Loop 确认”后在浏览器核对动作、资源、到期时间和可重复使用性。确认或拒绝后原任务会自动收到结果。业务管理动作需明确授权，应用委托限具体应用及动作。已有授权可在 Loop 账号设置中查看和撤销。

## 使用业务能力

从侧栏打开任务。从“更多”打开收件箱、通讯录、项目、工作流、知识库、云盘、数据空间、专家 · 技能或连接器。输入 `/` 选择当前有权读取的 Loop 知识库或 Skill；选择不增加权限。输入 `@` 或用自然语言选择同事和 Agent；普通提及不建任务、不通知。派工必须来自本轮真实用户消息，并确认必要的分享范围。

插件提供按需 Skill 和 `loop-proxy` 虚拟命令。它们由宿主工具接口在 shell 之前处理，模型无需全局可执行文件。具体动作仍由 Loop 校验。模型目录自动刷新，可用模型显示在 DSH 原生选择器中。

## 上传、退出与升级

会话上传只采集可见内容，默认只上传登录期间的新事件。“上传未登录期间的聊天”开启后才补传可访问的历史。隐藏推理、原始工具参数、文件内容和凭据不会随对话上传。

退出冻结当前连接，完成服务端撤销后清理对应本地凭据。未知结果保留可恢复状态，不报告撤销成功，也不影响其他安装。关闭插件不等于退出账号。

升级时保留 DSH Home、原会话、队列和旧发布包。旧 Go 连接凭据不会自动导入原生 provider，需重新登录。回退不得覆盖升级后的账本。详见[原生安装说明](../../../../plugins/loop-proxy-dsh/README.native.md)。
