# Loop for DeepSeek Harness v2.0.0

## Highlights

- **Unified Machine + Attached Runtime Architecture**: Replaces the legacy standalone external-agent / yamux proxy stack with Loop's native `Machine` + `loop daemon` + attached `deepseek-harness` Runtime + standard `Agent` model.
- **OAuth 2.1 + PKCE One-Step Bootstrap**: Authenticates against `/api/v1/auth/oauth/*`, provisions or reuses your workspace `Machine` and `deepseek-harness` `Agent`, and runs `loop connect`.
- **Automatic Headless Daemon Provisioning**: Reuses an existing Loop Desktop / CLI `loop daemon` (`~/.loop/run/daemon.json`), supports custom `loopServerUrl` and `loopBinaryPath` overrides, and automatically downloads + SHA-256-verifies `~/.loop/bin/loop` when needed.
- **Bidirectional Session Sync & `local_only` Privacy Mode**: Bridges live Loop scopes and DSH sessions over `/api/internal/runtimes/deepseek-harness/{attach,status,bindings,local-turns}` with echo fencing.
- **Pure JavaScript Package**: Removes `koffi` and `@libp2p/yamux` native/tunnel dependencies.
