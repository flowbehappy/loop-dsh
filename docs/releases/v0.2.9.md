# Loop for DeepSeek Harness v0.2.9

本版在模型首次接触插件时说明 Loop 工作区身份与 DSH 本地子智能体的范围，并直接提供已有的 `loop-proxy actions` 能力发现入口。模型仍自主选择操作和顺序；引用、发现与授权保持分离。

- 同一个发现入口适用于结构化引用、直接说名称和授权模型自行选择协作者；没有新增按名称、话术或案例触发的分支。
- 新增六项真实模型发现验收，每项从新会话开始，通过 Loop API 核对任务、负责人、频道成员和消息。验收覆盖只读请求及引用文字不触发派工。
- 包含 v0.2.8 之后主分支已有的通用契约改进：个人身份动作发现、精确授权、结构化错误及显式参数传递。已公开便捷工具保留兼容。
- 增加按版本标签构建、校验和发布安装包的 GitHub Actions 流程。

安装文件为 `loop-dsh.tgz`，校验文件为 `loop-dsh.tgz.sha256`。通过 DSH 的第三方插件安装入口更新后，按提示重启。

验证范围和限制：

- 本仓静态检查通过；自动测试 824 项通过，11 项环境门控跳过。
- DeepSeek 实际模型、官方 DSH 0.2.2-rc.1 与隔离 Loop：六项发现验收通过，按服务端状态核对结果。原版基线的六项也通过，不能据此量化模型成功率提升。
- 同事截图中的具体模型误判尚未在隔离基线中复现；本版属于通用契约说明改进，不保证模型每次都作出正确选择。
- 本轮不包含 Windows/Linux 桌面端或 macOS Desktop GUI 验收。CLI、官方运行时和界面验收分别记录。
- 此前 Human-only 私有话题读写的真实模型验收曾失败，本轮未复验这些历史业务分组，不将它们视为已修复。
